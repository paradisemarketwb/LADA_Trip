# LADA Trip · downloads

Android 9 test build for ARM 32-bit (`armeabi-v7a`), built from source commit `450d055`.

- `LADA-Trip-Android9-ARM.apk` — main application.
- `LADA-CAN-Probe.apk` — optional diagnostic utility.
- `SHA256SUMS.txt` — download checksums.

Both APKs use the Android debug signature. An in-place update requires a matching signature on the installed build.
