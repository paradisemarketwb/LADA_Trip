# Публикация LADA Trip в публичном GitHub

## Быстрый запуск (Windows 10/11)

1. Распакуйте ZIP в новую папку, например `C:\LADA-Trip-Public`.
2. Откройте папку `lada-trip` и дважды запустите **`CREATE-PUBLIC-GITHUB.cmd`**.
3. Если GitHub CLI ещё не установлен, скрипт предложит установку через `winget`. При первом запуске авторизуйтесь в браузере под `paradisemarketwb`.
4. Скрипт создаст **новый публичный** `paradisemarketwb/LADA_Trip`, отправит исходники и попытается установить две защиты `main`.
5. Откройте вкладку **Actions**, дождитесь результата `Build Android debug APK`, скачайте артефакт `LADA-Trip-v0.2-engineering-debug-apk`.

## Права доступа

- Сторонние пользователи могут читать исходники и делать форки, но без выданного вами доступа **не могут менять оригинальный репозиторий**.
- Скрипт не добавляет collaborators и отключает Issues/Wiki/Discussions.
- Правила ветки `main`: только пользователи с ролью администратора могут её обновлять; запрет удаления/force-push. Проверьте состояние правил в **Settings → Rules → Rulesets**. Если GitHub отклонит настройку, будет предупреждение.
- Проверьте **Settings → Collaborators** и установленные приложения с доступом на запись: не давайте доступ другим аккаунтам или ботам, которым не доверяете.

## Конфиденциальность

- Этот исходный пакет не содержит реальных токенов Telegram, ключей сервера, GPS-маршрутов, личных сообщений или MFi-материалов.
- `server/.env.example` содержит только шаблонные значения. Настоящий `server/.env` **никогда не коммитьте**.
- Логи GitHub Actions публичны: не выводите секреты в CI.
- Проект публикуется **без лицензии**. Публичное чтение не означает автоматического разрешения на использование или распространение кода; пользовательские форки GitHub всё равно возможны.

## Если сборка APK не пройдёт

Посмотрите журнал `Actions → Build Android debug APK → Compile debug APK` и передайте текст ошибки. Исторические проверки Java/XML не равны полноценной Android-сборке.

## Альтернатива: создать репозиторий через сайт

Если не хотите устанавливать GitHub CLI, откройте https://github.com/new, укажите `LADA_Trip`, `Public`, не добавляйте README, `.gitignore` и LICENSE. Создайте репозиторий и пришлите его ссылку; исходники можно загрузить через подключённый GitHub.
