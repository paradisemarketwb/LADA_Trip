# Приёмка на LADA EnjoY Vision Pro — версия 0.1

## До установки
1. Соберите debug APK в Android Studio или скачайте workflow artifact из GitHub Actions (после публикации проекта).
2. Сделайте резервную копию важных пользовательских данных. APK не требует root и не заменяет системные приложения.
3. При необходимости установите APK с USB штатным установщиком (если прошивка разрешает сторонние APK).

## Проверка 1 — GPS без интернета
1. Отключите Wi-Fi/мобильный интернет; включите штатную геолокацию.
2. Запустите LADA Trip, разрешите местоположение, нажмите **Старт GPS**.
3. Пройдите или проедьте по открытому пространству; проверьте появление координат и уведомления.
4. После движения (два подтверждения GPS) поездка должна появиться в истории. При остановке свыше 1 минуты будет учтена остановка, после 8 минут без движения поездка завершится.
5. Закройте экран LADA Trip и снова откройте: запись должна продолжаться, если магнитола не убивает foreground-service.

## Проверка 2 — доставка Telegram
1. Настройте сервер HTTPS и ключ устройства по `server/README.md`.
2. В приложении задайте адрес, ID и **ключ устройства** (НЕ токен Telegram).
3. Отключите интернет, нажмите "Отправить последнюю точку", проверьте рост очереди.
4. Включите интернет: ожидается сообщение со ссылкой на Google Maps, временем GPS и точностью. Очередь должна уменьшиться после подтверждения сервера.
5. Повторите с отключённым сервером: не более 3 попыток на цикл; после следующего подключения сообщение остаётся с тем же event_id и повторяется. Случайное повторное HTTP POST с тем же event_id не должно создавать второе Telegram сообщение.

## Проверка 3 — автозапуск и сон
1. Активируйте "Автозапуск мониторинга" и **Старт GPS**.
2. Выключите/включите магнитолу обычным образом. Проверьте: был ли `BOOT_COMPLETED` (полная перезагрузка может отличаться от сна), появилось ли уведомление.
3. Сравните GPS-метки после выключения и включения: работа во сне зависит от штатной прошивки.
4. Если мониторинг не запустился, экспортируйте JSON диагностику и отметьте характер выключения (сон / холодный старт).

## Проверка 4 — USB
Вставьте флешку → откройте "Журнал точек CSV", "Маршруты GPX", "Диагностический JSON" → в окне сохранения выберите USB. Если штатный Android не показывает USB в системном файловом провайдере, зафиксируйте это: это OEM-ограничение, не ошибка GPS.

## Реальные ограничения первой версии
- Приложение не может включить аппаратное питание GPS или пробудить полностью выключенную магнитолу.
- Android 9 может блокировать BOOT_COMPLETED/сервисы на уровне OEM.
- Начало/конец определяются **по GPS движению**, CAN/ACC/зажигание пока не считываются.
- Интернет и GPS не обязательны одновременно. При задержке доставки указывается исходное время записи.
- Сырой GPS может давать ошибочные скачки: фильтр игнорирует неточные фиксы (>80 м) и невозможные скорости (>65 м/с).
- Отправка координат только на явно настроенный сервер авторизованного устройства. Оповещения видны при доступе к Telegram-чату.
